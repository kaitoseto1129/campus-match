キャンマッチについて

キャンマッチは、大学が発行するメールアドレスで在学確認を行う、学生限定のマッチングアプリです。 同じ大学・近くの大学に通う学生同士が、趣味や共通点をきっかけに出会えます。

  • 大学メールアドレスによる在学確認
  • 趣味カードで共通の話題からお相手を探せる
  • 通報・ブロック・非表示機能で安心して利用できる

登録できるのはどんな人ですか?

18歳以上で、大学等の高等教育機関に在学中の方のみご利用いただけます。 登録には、在学する大学が発行するメールアドレスが必要です。

有料会員を解約したい

iOSの「設定」→ 一番上のApple ID →「サブスクリプション」→「キャンマッチ」から解約できます。 アプリを削除しただけでは解約されませんのでご注意ください。

機種変更したら有料会員が反映されない

アプリ内の「マイページ」→「会員ステータス」を開き、「購入を復元」をタップしてください。

退会したい

アプリ内の「マイページ」→「退会する」から、いつでもご自身でアカウントを削除できます。 退会するとプロフィール、写真、トーク履歴などのデータは削除され、元に戻せません。

不快なユーザーがいる

お相手のプロフィール画面またはトーク画面の右上のメニューから、 「非表示にする」「ブロックする」「違反報告する」が行えます。 通報いただいた内容は運営者が確認し、規約違反が認められた場合は利用停止等の対応を行います。
