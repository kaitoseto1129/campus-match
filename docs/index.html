キャンマッチについて

キャンマッチは、大学が発行するメールアドレスで在学確認を行う、学生限定の集まりアプリです。 同じ大学に通う学生同士で、ご飯・勉強・スポーツ・イベント参加などの少人数の集まりを募集し、 参加が決まったメンバーでグループトークをしながら待ち合わせができます。

  • 大学メールアドレスによる在学確認
  • 性別を問わず、同じ大学の学生なら誰でも応募できる
  • 連絡は集まりごとのグループトークのみ(1対1の個別メッセージ機能はありません)
  • 通報・ブロック・非表示機能で安心して利用できる
キャンマッチは、異性交際(恋愛・デートを目的とした交際)の相手を紹介するサービスではありません。 異性交際を目的としたご利用は利用規約で禁止しています。

登録できるのはどんな人ですか?

18歳以上で、大学等の高等教育機関に在学中の方のみご利用いただけます。 登録には、在学する大学が発行するメールアドレスが必要です。

退会したい

アプリ内の「マイページ」→「退会する」から、いつでもご自身でアカウントを削除できます。 退会するとプロフィール、写真、参加した集まり、グループトークの履歴などのデータは削除され、元に戻せません。

不快なユーザーがいる

集まりの詳細画面またはグループトーク画面の右上のメニューから、 「非表示にする」「ブロックする」「違反報告する」が行えます。 通報いただいた内容は運営者が確認し、規約違反が認められた場合は利用停止等の対応を行います。
